# worklog

`worklog` — read-only CLI-утилита для получения краткого отчета о работе разработчика в Git-репозитории.

Утилита показывает, над какими ветками пользователь работал, какие значимые Git-действия выполнял, а также текущие и сохранённые в stash файлы.

## Команды

```bash
worklog today
worklog yesterday
worklog status
```

### `worklog today`

Показывает активность за сегодняшний календарный день:

- собственные коммиты;
- завершённые merge, rebase, cherry-pick и revert, подтверждённые локальным reflog;
- push и force-push, подтверждённые reflog удалённой отслеживаемой ветки;
- stash, созданные сегодня;
- файлы из этих stash;
- текущие незакоммиченные файлы.

Fetch не выводится как push. Текущее состояние upstream (`ahead`, `behind` или `synchronized`) показывается отдельно от исторических событий.

### `worklog yesterday`

Показывает подтверждённые исторические действия и stash за предыдущий календарный день. Текущий status и текущее upstream-состояние в отчёт не входят.

### `worklog status`

Показывает snapshot текущих незакоммиченных файлов и upstream-состояние текущей ветки.
